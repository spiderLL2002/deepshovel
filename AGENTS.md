# Public source and reproducibility scope

This is the clean public snapshot of DeepShovel, licensed under AGPL-3.0-only. Do not add credentials, private environment files, local databases, source collections or model weights. Use the example configuration files and keep generated runs under `runs/`.

Reproduction and documentation changes in this public checkout do not authorize deployment to the maintainer's shared public service. Preserve original scientific exports and historical evaluations; write new verification results to a new directory. AI executions and synthetic fixtures must remain explicitly labeled.
