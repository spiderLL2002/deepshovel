# Revised figure captions

**Figure 1. Recorded station positions and changing sampling support.** (A) Positions of the 14 stations with eligible primary bottles, using the original REE files' recorded start coordinates. The map is a coordinate plot, without a coastline, area weights or an inferred water-mass boundary. Markers use the median recorded coordinate of eligible bottles at each station; every recorded coordinate and its source line remains in station_geometry.json. (B–C) Eligible bottle memberships in all six primary inclusive 100 m layers, including explicit zeros. An asterisk identifies stations represented in every layer. Leg 1 uses 24 unique bottles/28 memberships; Leg 2 uses 55 bottles/63 memberships. Boundary records can occur in adjacent layers and are not additional independent samples. Stations 16 and 18 are present in every Leg 1 layer; 31 and 33 are present in every Leg 2 layer. Missing stations are not recovered by within-layer station weighting. The plotted layer means therefore describe actual eligible samples rather than an area-weighted or geographically complete regional profile. Source: frozen review diagnostic station_layer_support.csv, station_layer_support_long.csv and station_geometry.json; plotting coordinates and original CSV row locators are in fig01_source_values.csv. Data plots were produced by reproducible Python code developed with Codex assistance.

**Figure 2. Fixed predictions compared on actual sampled layer means.** Measured GP15 total-scale pH at 25 °C, unchanged REE predictions and the original fixed global-depth reference are compared for both legs on identical bottle support. Axes are identical. Neighboring layers can contain different station groups, as shown in Figure 1; joining points is a visual guide and does not establish a vertical profile at fixed spatial support. The reference is a comparator, not locally measured truth. The comparison does not apply area weighting or infer representative regional means. Source: the original frozen primary layer_summary.csv; full-precision plotting values and sample/station memberships are reproduced in fig02_source_values.csv. Data plots were produced by reproducible Python code developed with Codex assistance.

**Figure 3. Descriptive mean-offset and centered-error contributions.** Each bar shows the exact decomposition of six-layer MSE into squared mean error and centered MSE, for both fixed predictions and both legs. The two pieces sum to the original MSE; labels give original RMSE in pH units. Leg 2 REE mean error is +0.211 pH and its square contributes 93.3% of total MSE. Centered error retains discrepancies after subtracting the target-observed mean error for diagnosis only. It is neither a validated bias correction nor a new model performance; no refit, interval or additional independent test is represented. Source: mse_decomposition.csv, independently reconstructed from the original matched observations; full-precision values in fig03_source_values.csv. Data plots were produced by reproducible Python code developed with Codex assistance.

**Figure S1. Original fixed aggregation and station-deletion checks.** All four prespecified aggregation variants and both legs are retained from the original R8 analysis. Points are REE-minus-fixed-depth-reference RMSE on matched support; negative values favor the REE model. Bars on the primary rows span every individual station deletion, and are sensitivity ranges rather than confidence intervals. The Leg 1 half-open variant retains a weak layer, with only five layers meeting the three-station criterion. This supplementary panel redraws the original coordinates and deletion ranges without numerical changes; neither the number of scenarios nor the number of deletion cases is an independent sample size. Source: original aggregate_summary.json and leave_one_station_out.json; exact plotted values in figS01_source_values.csv. Data plots were produced by reproducible Python code developed with Codex assistance.

**Figure S2. Original calibration reference and all sampled primary means.** Black diamonds are the original six training reference means; colored points are measured GP15 pH means and their corresponding REE features. The original training code accepts nonmissing G2phts25p0 values from the merged GLODAP product and does not impose a direct-pH-measurement-only restriction; the calculated-value fraction in the training subset is not established. The y-axis therefore identifies mean pH without calling every training value a direct observation. The solid fixed line spans the original alpha feature range and dashed segments extrapolate. Grey shading represents feature support, not joint alpha–pH validity or a confidence region. All 12 GP15 primary layer means remain, including target-pH departures among points with in-range alpha. This descriptive domain annotation does not change selection, scoring or the original calibration. Source: saved original training means and original frozen GP15 outputs; coordinate values unchanged in figS02_source_values.csv. Data plots were produced by reproducible Python code developed with Codex assistance.

## Reproduction and interpretation

All new figures are presentation artifacts, not new experiments or independent validation. Figures 1 and 3 use the root-frozen post-review diagnostic v2; Figure 2 uses unchanged R8 primary outputs. Figure S1 redraws the existing manuscript panel from its unchanged original coordinate and range table. Figure S2 redraws those same saved coordinates with corrected training-pH provenance wording. The script writes only inside this revision figure directory and a new generated supplementary v3 table file. It does not write original raw data, frozen programs, protocols, results or central state. PNG files are 450 dpi and SVG text remains editable. Source hashes, field mappings and output hashes are in figure-source-manifest.json.
