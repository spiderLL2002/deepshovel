# One-record recipient reconstruction check

This is a format-retention illustration using one actual saved F2 record. The deliberately defined minimal projection contains exactly prepared_value, unit and DOI; it is not an implementation of SciDaSynth, LitCurate, another CSV tool, or all possible table schemas. No performance or usability superiority is inferred. The full JSON-LD input is produced from the same actual record by the released exporter.

A fresh AI recipient is asked to recover six concrete items from only each input: (1) prepared value/unit; (2) original selected-observation numeric/raw/unit; (3) prepared quantity/conditions; (4) selected observation/claim identity and actual directed terminal relation; (5) source-version SHA and recorded/corrected locator information; (6) operator conclusion and qualification. Missing information must remain unavailable, without external source lookup or guessing. Queries or parsing commands and exact input locators must support every answer.

The result is a single-AI reconstruction of retained information. The projection's missing fields are absent by construction; they are not a measured competitor failure, random-corpus result, human comprehension or scientific-correctness rate. Inputs/selection fixed before the recipient acts.
