# WWW 2027 demonstration manuscript

[Read the four-page PDF](main.pdf). Build the source with `tectonic main.tex` from this directory. The only screenshot is the genuine public-service capture in `../artifact/live-demo/04-assumptions.jpg`; the paper applies a crop. Tectonic resolves the ACM class from its TeX bundle.

The paper describes fixed historical research records and separately executable checks. Start with the repository README to run them. The release tag binds this paper to its source and data packages.
